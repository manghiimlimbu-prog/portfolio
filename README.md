# Manghim Limbu Chemjong — Developer Portfolio

A responsive software developer portfolio created with HTML, CSS and JavaScript and published using GitHub Pages.

## Sections
- Professional summary
- Education
- Technical skills
- Academic projects
- Resume and experience
- Contact information

## Before publishing
1. Replace `REPLACE_WITH_YOUR_EMAIL` in `index.html` with your professional email.
2. Replace the `emailDisplay` placeholder text with the same email.
3. Upload your real resume as `resume.pdf` in the repository root.
4. Verify all project descriptions and experience details for accuracy.
5. Test all links, project filters and mobile navigation.

## Deployment
In GitHub repository Settings > Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**.

Live site: https://manghimlimbu-prog.github.io/portfolio/

## Featured Projects

### 1. HamOnTap – Water Fountain Locator

A web application that helps users discover public drinking
water fountains throughout Hamilton, Ontario.

Features:

- Interactive map with fountain locations
- Location-based fountain discovery
- Filtering by fountain type and ward
- Directions to nearby fountains
- Fountain reporting functionality
- Responsive user interface

Technologies: JavaScript, HTML, CSS, Google Maps

### 2. The Board Game Vault

A WordPress website developed for a fictional board-game
venue, featuring information about games, events, and
community activities.

Features:

- Games and rentals information
- Events calendar
- Job listings
- Blog articles
- Contact form and interactive map
- Customized WordPress child theme

Technologies: WordPress, PHP, HTML, CSS, MySQL

### 3. Doctor Who Database Application

A Windows Forms desktop application that displays
information about Doctors and their companions.

Features:

- Interactive Doctor selection
- Companion information display
- Database integration
- SQL and LINQ query options
- Dynamic image and information updates

Technologies: C#, .NET, SQL Server, Windows Forms

### 4. Java Dictionary Search and Hash Table Analysis

A Java application developed to compare dictionary
search methods and analyze data structure performance.

Features:

- Processing large text files
- Linear search
- Binary search
- HashSet-based searching
- Execution time comparison
- Hash table statistics

Technologies: Java, Data Structures, Algorithms
